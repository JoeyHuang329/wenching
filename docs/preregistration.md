## 1. 分析樣本與範圍（提案書 6.1、6.2）

- **主範圍：** 南京西路、民權西路、環河北路、延平北路圍成的區域。邊界檔為 `config/boundary_main.geojson`（以打 tag 時的版本為準）。
- **沿街納入：** 以界線道路中心線定義的主範圍，向外擴 10 公尺納入沿街店家建物形心；0 公尺與 15 公尺外擴列為敏感度分析。
- **緩衝區：** 主範圍外 300 公尺（含大橋頭），由主範圍以 EPSG:3826 外擴 300 公尺產生（`config/boundary_buffer.geojson`）。緩衝區的 POI **只用來計算鄰域特徵**，不進任何假說檢驗。
- **分析單位：** 主範圍內、`business_status = OPERATIONAL`、且不屬於非商業類別（`config/settings.yaml` 的 `noncommercial_types`）的 POI。
- **街區：** 以 OSM 道路（排除 `settings.yaml` 的 `streets.exclude_highway` 類別，即小巷與步道）切割主範圍得到封閉塊。
- **街區合併規則：** 街區內的分析單位 POI 少於 15 個時，與「共用邊界最長」的相鄰街區合併；從 POI 最少的街區開始，反覆合併到所有街區都 ≥ 15 個 POI 為止。合併結果存成 `block_id`，同時用在固定效果、群集標準誤與空間區塊交叉驗證。
- **敏感度分析（只對 H6）：** 把大橋頭（緩衝區中重慶北路三段一帶）納入分析樣本，重跑 H6 一次。時間不足時移至未來工作，不影響主結果。

## 2. 操作型定義（提案書第 6 節）

### 2.1 業態大類（6.3）

由 Places 類別與 LLM 抽取共同決定，值域：熱食餐飲、咖啡茶飲甜點、傳統業種、選物與文創零售、文化空間、一般零售與品牌、其他。「其他」排除於 H6。H6 的客流型態對應：熱食餐飲＝目的型；咖啡茶飲甜點＝混合；傳統業種＝目的型與批發；選物與文創零售、文化空間、一般零售與品牌＝路過型。

H3 將「傳統業種」細分為中藥與南北貨：依店名關鍵字判定，規則列於 `config/settings.yaml` 的 `traditional_subtypes`，於打 tag 時凍結。店名先正規化，再依設定檔順序取第一個命中的細類；細分不依賴 LLM。中藥關鍵字為「藥行、參藥、蔘藥、中藥、漢藥、藥材、草藥、青草」；南北貨關鍵字為「南北貨、乾貨、海味、海產乾貨、食品行、魚翅、干貝、香菇、臘味」。關鍵字僅依店名，無法辨識店名不含關鍵字的店家，預期造成南北貨召回率偏低；打 tag 後不再增刪關鍵字，若需修改則記入 `docs/deviations.md`。

### 2.2 文青（6.4）

符合任一條件即為文青，且連鎖一律排除：
1. 獨立（非連鎖）咖啡店或茶空間，不需其他條件。
2. 屬白名單業態（獨立書店、選物與文創、手作與工藝、藝廊與展演、設計工作室），且自我敘事中至少有一項風格指標（設計或美學主張、在地或歷史故事、手作或小量生產、閱讀或展覽活動）。

`wenqing_group` 由程式依上述規則從 `fine_type`（細業態）、`is_chain`、`style_*` 推導，不直接叫 LLM 判斷（`src/dadaocheng/extraction.py` 的 `derive_wenqing_group`）。三群：咖啡與茶空間、閱讀與展演、選物與工藝；其餘為非文青。轉型中的老店不算文青，但記錄歷史敘事。

- `fine_type` 是實作規劃 B 第 3.2 節之外新增的抽取欄位：只有 `category` 分不出「咖啡店／茶館」與「手搖飲」、「獨立書店」與其他文化空間，規則無法機械地套用。
- `is_chain = 不明` 時視為非文青。敏感度分析另將不明視為獨立，重算 H5、H6 的相關結果。
- `fine_type = 甜點烘焙` 者，需至少一項風格指標（設計或美學主張、在地或歷史故事、手作或小量生產、閱讀或展覽活動）才歸入「咖啡與茶空間」，對應提案書「空間型甜點店」。

### 2.3 歷史的三個變數（6.5）

| 變數 | 定義 |
|---|---|
| 建築歷史屬性 `in_heritage` | POI 落在登錄歷史建築或古蹟的建物輪廓內，或距離 ≤ 15 公尺；只有地址時以正規化地址比對。以 10 與 12 公尺門檻另作敏感度分析 |
| 歷史環境密度 `heritage_kde_150`、`heritage_kde_300` | 以歷建、古蹟、百年廟宇為點，高斯核、帶寬 150 與 300 公尺的核密度（EPSG:3826）。H6 主模型用 300 公尺版本 |
| 歷史敘事 `history_narrative` | LLM 抽取：無／建築／街區／家族（可複選） |

### 2.4 結果變數（6.6）

- **關注度：** `log(1 + user_rating_count)`。
- **店齡：** `店齡 = 2026 − founded_year`。抽不到或年份早於 1800、晚於 2026 者視為缺失。主規格不含店齡；敏感度分析以缺失指標加中位數補值納入店齡。若含店齡與不含店齡的方向不一致，以不含店齡的主規格為準，並於限制中說明。
- **成功：** 仍在營業，且關注度高於同業態大類中位數。只用於 RQ3，主流程不做退場分析。

### 2.5 營業時間（H1）

- `close_time_weekday`：週一到週五各天關門時間的中位數。跨午夜（關門時間早於開門時間，或 Places 的 close.day 為隔天）以「24 時 + 關門時刻」計。
- `closes_before_19`：`close_time_weekday < 19:00`。
- 沒有營業時間的 POI 是**缺失**，不是「不營業」，排除於 H1 分母，並報告缺失比例。24 小時營業視為不在 19:00 前關門。週一至週五皆無營業時段者，因 `close_time_weekday` 無定義，排除於 H1 分母，另報家數與業態分布。

## 3. 假說

### H1　夜間經濟弱，多數店家傍晚就打烊（核心）

| 項目 | 規格 |
|---|---|
| 變數 | `closes_before_19`；業態大類 |
| 估計 | 「平日 19:00 前關門」的比例與 95% 信賴區間：整體、分業態大類、主街對巷弄 |
| 信賴區間 | 以街區為單位的群集自助法，2,000 次重抽，作為主要區間；Wilson 區間一併報告作為對照。證偽判準以群集自助法 95% 區間上界為準 |
| Holm 用的 p 值 | 整體比例的單尾精確二項檢定，H₀：p ≤ 0.5 |
| p 值解讀 | Holm 用的精確二項 p 值假設店家獨立；考量街區內相關，該 p 值可能偏小，信賴區間與證偽判定以街區群集自助法為準 |
| 證偽 | 整體比例的 95% 信賴區間上界低於 50% |
| 業態變數來自 LLM 時 | 分業態的比例報告直接版與 PPI 修正版 |

### H3　業種分區：主街中藥、巷弄文創、民生西路以北南北貨（核心）

| 項目 | 規格 |
|---|---|
| 變數 | 業態大類（傳統業種細分中藥、南北貨）、`on_main_street`、座標、是否在民生西路以北 |
| 三個分區描述 | (a) 中藥集中在主街；(b) 文創（選物與文創零售，及文青店）集中在巷弄；(c) 南北貨集中在民生西路以北 |
| 檢定 | 每個描述：該業種落在指定區位的比例，對照所有分析單位 POI 落在該區位的比例。置換檢定：固定 POI 位置、洗牌業種標籤 999 次，單尾 |
| 輔助指標 | 中藥、文創、南北貨三組的共同區位商數（CLQ，A→A），用同一套置換檢定；作為描述，不另算 Holm |
| Holm 用的 p 值 | 三個描述的置換檢定 p 值中的第二小者（至少兩個描述成立才算支持）；三個個別 p 值一併報告，不另作校正。可計算的描述少於兩個時，H3 判定為「無法檢定」，不提供 Holm p 值；Holm 家族大小仍固定為 m = 4 |
| 證偽 | 三個分區描述中有兩個以上不顯著 |
| 業態變數來自 LLM 時 | 直接版與 PPI 修正版 |

### H5　歷史建築限制熱食與明火（核心）

| 項目 | 規格 |
|---|---|
| 變數 | `in_heritage`；是否為熱食餐飲 |
| 檢定 | 2×2 列聯表與 Fisher 精確檢定（單尾：歷建內熱食比例較低）；以街區分層的 Mantel–Haenszel 檢定作為穩健性 |
| Holm 用的 p 值 | Fisher 單尾 p 值 |
| 證偽 | 歷建內熱食比例不低於歷建外 |
| 報告層級 | 主街與巷弄分層結果為主要報告，合併結果為次要報告。此分層係看過初步結果後新增，屬探索性分析；Holm 校正仍使用事前規格的合併 Fisher 單尾 p 值 |
| 檢定力 | 歷建內 POI 少於 20 家時，報告「檢定力不足」，不改用其他檢定 |
| 業態變數來自 LLM 時 | 直接版與 PPI 修正版 |

### H6　歷史環境的關聯因業態而異（核心，主問題）

| 項目 | 規格 |
|---|---|
| 模型 | `log(1 + 評論數) = 歷史密度(300 m) × 業態大類 + 是否連鎖 + 是否位於主街 + 捷運距離 + 價位 + 街區固定效果`；街區固定效果層級為合併後的 `block_id` |
| 推論 | 主要 p 值使用 Webb 權重的 wild cluster bootstrap（9,999 次），不以一般群集穩健 p 值作主要推論；附錄報告 leave-one-cluster-out 分析 |
| 樣本 | 分析單位 POI，排除業態「其他」 |
| 參照類別 | 熱食餐飲（目的型）；參照類別只影響個別交互項的解讀，不影響交互項聯合檢定。主要呈現各業態自己的歷史密度斜率，不以相對參照組的差異為主 |
| 尺度 | 歷史密度在分析單位全樣本（排除業態「其他」前）內標準化為平均 0、標準差 1；150 公尺版本各自標準化。不在街區內另行標準化 |
| Holm 用的 p 值 | 所有「歷史密度 × 業態」交互項的聯合 Wald 檢定；p 值以 Webb 權重 wild cluster bootstrap 計算 |
| 證偽 | 先在任何 H6 係數估計前，依設計條件計算 80% 檢定力下的 MDE。若 MDE ≤ 0.10，只有在所有交互項的 95% 信賴區間均涵蓋 0 且完整落在 ±0.10 log 單位內時才判定證偽；若 MDE > 0.10，設計無法分辨零與 ±0.10 內的效果，不宣稱證偽，只表述「未發現達 MDE 以上的效果」，並於限制中說明。±0.10 log 單位約對應評論數 10.5% 的變動；此等效界線為本研究自行設定，非文獻慣例 |
| 頻寬與報告 | 300 公尺為主規格；150 公尺列敏感度分析。報告街區內／總標準差比（300 公尺為 0.480），並說明識別力偏弱 |
| 檢定力 | 在開始 H6 估計前，以 n 約 1,298、街區內／總標準差比 0.48、街區數約 17–22 為設計條件，計算並報告 80% 檢定力下的最小可檢測效果（MDE） |
| 店齡敏感度 | 主規格不含店齡；另依第 2.4 節的規則納入店齡及缺失指標進行敏感度分析。兩者方向不一致時，以不含店齡的主規格為準 |
| 報告 | 各業態自己的歷史密度斜率與信賴區間（森林圖）；直接版與 PPI 修正版（業態與連鎖來自 LLM 時）。`ppi_py` 若不支援固定效果加群集標準誤，先以街區去平均處理固定效果，再用其 OLS 版本，並記錄在 deviations.md。文化空間（57 家、散布於 14 個街區）不作固定效果交互項估計，改作描述性分析並說明樣本不足 |
| 租金 | 無法直接觀測。街區固定效果與「是否位於主街」吸收街區層級的租金差異（提案書 5.2） |
| 敏感度 | 納入大橋頭重跑一次（時間允許） |

### RQ2　LLM 建構特徵的分析目標

- 依 `is_wenqing` 的 κ 預先分流：κ ≥ 0.61 時以 `is_wenqing` 為主要目標；κ 為 0.41–0.60 時以 `category` 為主要目標，並以 PPI 校正後結果呈現 `is_wenqing`；κ < 0.41 時只以 `category` 為量化目標。
- 不對文青子類別作量化分析；改以描述性分布圖與文字呈現。

|---|---|

## 5. 什麼情況算偏離預先登錄

任何對第 1–3 節的變更（範圍、定義、模型、檢定、證偽條件、Holm 的組成）都要在 `docs/deviations.md` 記錄日期、原因與對結論的影響。資料清理的細節（例如名稱正規化規則）不算偏離，但要寫在程式與 config 中。
