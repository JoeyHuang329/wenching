## 1. 分析樣本與範圍（提案書 6.1、6.2）

- **主範圍：** 南京西路、民權西路、環河北路、延平北路圍成的區域。邊界檔為 `config/boundary_main.geojson`（以打 tag 時的版本為準）。
- **緩衝區：** 主範圍外 300 公尺（含大橋頭），由主範圍以 EPSG:3826 外擴 300 公尺產生（`config/boundary_buffer.geojson`）。緩衝區的 POI **只用來計算鄰域特徵**，不進任何假說檢驗。
- **分析單位：** 主範圍內、`business_status = OPERATIONAL`、且不屬於非商業類別（`config/settings.yaml` 的 `noncommercial_types`）的 POI。
- **街區：** 以 OSM 道路（排除 `settings.yaml` 的 `streets.exclude_highway` 類別，即小巷與步道）切割主範圍得到封閉塊。
- **街區合併規則：** 街區內的分析單位 POI 少於 15 個時，與「共用邊界最長」的相鄰街區合併；從 POI 最少的街區開始，反覆合併到所有街區都 ≥ 15 個 POI 為止。合併結果存成 `block_id`，同時用在固定效果、群集標準誤與空間區塊交叉驗證。
- **敏感度分析（只對 H6）：** 把大橋頭（緩衝區中重慶北路三段一帶）納入分析樣本，重跑 H6 一次。時間不足時移至未來工作，不影響主結果。

## 2. 操作型定義（提案書第 6 節）

### 2.1 業態大類（6.3）

由 Places 類別與 LLM 抽取共同決定，值域：熱食餐飲、咖啡茶飲甜點、傳統業種、選物與文創零售、文化空間、一般零售與品牌、其他。「其他」排除於 H6。H6 的客流型態對應：熱食餐飲＝目的型；咖啡茶飲甜點＝混合；傳統業種＝目的型與批發；選物與文創零售、文化空間、一般零售與品牌＝路過型。

H3 需要把「傳統業種」細分為中藥與南北貨：依 Places 類別或名稱關鍵字，規則寫在 `config/settings.yaml`（【待確認】：關鍵字清單需在打 tag 前寫入 config，例如中藥＝「藥行、參藥、中藥、蔘」；南北貨＝「南北貨、乾貨、海味、行（且非藥行、布行）」）。

### 2.2 文青（6.4）

符合任一條件即為文青，且連鎖一律排除：
1. 獨立（非連鎖）咖啡店或茶空間，不需其他條件。
2. 屬白名單業態（獨立書店、選物與文創、手作與工藝、藝廊與展演、設計工作室），且自我敘事中至少有一項風格指標（設計或美學主張、在地或歷史故事、手作或小量生產、閱讀或展覽活動）。

`wenqing_group` 由程式依上述規則從 `fine_type`（細業態）、`is_chain`、`style_*` 推導，不直接叫 LLM 判斷（`src/dadaocheng/extraction.py` 的 `derive_wenqing_group`）。三群：咖啡與茶空間、閱讀與展演、選物與工藝；其餘為非文青。轉型中的老店不算文青，但記錄歷史敘事。

- `fine_type` 是實作規劃 B 第 3.2 節之外新增的抽取欄位：只有 `category` 分不出「咖啡店／茶館」與「手搖飲」、「獨立書店」與其他文化空間，規則無法機械地套用。
- 【待確認】`is_chain = 不明`（多半是只有店名、無法判斷）時視為獨立。另一個選項是視為非文青；兩者會讓文青數量差很多，請在打 tag 前決定。
- 【待確認】甜點烘焙店需至少一項風格指標才算「咖啡與茶空間」（對應提案書「空間型甜點店」）。

### 2.3 歷史的三個變數（6.5）

| 變數 | 定義 |
|---|---|
| 建築歷史屬性 `in_heritage` | POI 落在登錄歷史建築或古蹟的建物輪廓內，或距離 ≤ 15 公尺；只有地址時以正規化地址比對 |
| 歷史環境密度 `heritage_kde_150`、`heritage_kde_300` | 以歷建、古蹟、百年廟宇為點，高斯核、帶寬 150 與 300 公尺的核密度（EPSG:3826）。H6 主模型用 300 公尺版本 |
| 歷史敘事 `history_narrative` | LLM 抽取：無／建築／街區／家族（可複選） |

### 2.4 結果變數（6.6）

- **關注度：** `log(1 + user_rating_count)`。
- **店齡控制：** LLM 從店家文本抽出的創立年份換算店齡；抽不到的以「缺失指標＋以 0 補值」處理（【待確認】：補值方式；建議缺失指標加上以中位數補值）。
- **成功：** 仍在營業，且關注度高於同業態大類中位數。只用於 RQ3，主流程不做退場分析。

### 2.5 營業時間（H1）

- `close_time_weekday`：週一到週五各天關門時間的中位數。跨午夜（關門時間早於開門時間，或 Places 的 close.day 為隔天）以「24 時 + 關門時刻」計。
- `closes_before_19`：`close_time_weekday < 19:00`。
- 沒有營業時間的 POI 是**缺失**，不是「不營業」，排除於 H1 分母，並報告缺失比例。24 小時營業視為不在 19:00 前關門。平日完全不營業者，排除於 H1 分母（【待確認】）。

## 3. 假說

### H1　夜間經濟弱，多數店家傍晚就打烊（核心）

| 項目 | 規格 |
|---|---|
| 變數 | `closes_before_19`；業態大類 |
| 估計 | 「平日 19:00 前關門」的比例與 95% 信賴區間：整體、分業態大類、主街對巷弄 |
| 信賴區間 | Wilson 區間（【待確認】：店家在街區內可能相關。若要保守，可改用以街區為單位的群集自助法；請在打 tag 前二擇一） |
| Holm 用的 p 值 | 整體比例的單尾精確二項檢定，H₀：p ≤ 0.5 |
| 證偽 | 整體比例的 95% 信賴區間上界低於 50% |
| 業態變數來自 LLM 時 | 分業態的比例報告直接版與 PPI 修正版 |

### H3　業種分區：主街中藥、巷弄文創、民生西路以北南北貨（核心）

| 項目 | 規格 |
|---|---|
| 變數 | 業態大類（傳統業種細分中藥、南北貨）、`on_main_street`、座標、是否在民生西路以北 |
| 三個分區描述 | (a) 中藥集中在主街；(b) 文創（選物與文創零售，及文青店）集中在巷弄；(c) 南北貨集中在民生西路以北 |
| 檢定 | 每個描述：該業種落在指定區位的比例，對照所有分析單位 POI 落在該區位的比例。置換檢定：固定 POI 位置、洗牌業種標籤 999 次，單尾 |
| 輔助指標 | 中藥、文創、南北貨三組的共同區位商數（CLQ，A→A），用同一套置換檢定；作為描述，不另算 Holm |
| Holm 用的 p 值 | 三個描述 p 值中的第二小者（即「至少兩個顯著」才算支持）（【待確認】） |
| 證偽 | 三個分區描述中有兩個以上不顯著 |
| 業態變數來自 LLM 時 | 直接版與 PPI 修正版 |

### H5　歷史建築限制熱食與明火（核心）

| 項目 | 規格 |
|---|---|
| 變數 | `in_heritage`；是否為熱食餐飲 |
| 檢定 | 2×2 列聯表與 Fisher 精確檢定（單尾：歷建內熱食比例較低）；以街區分層的 Mantel–Haenszel 檢定作為穩健性 |
| Holm 用的 p 值 | Fisher 單尾 p 值 |
| 證偽 | 歷建內熱食比例不低於歷建外 |
| 檢定力 | 歷建內 POI 少於 20 家時，報告「檢定力不足」，不改用其他檢定 |
| 業態變數來自 LLM 時 | 直接版與 PPI 修正版 |

### H6　歷史環境的關聯因業態而異（核心，主問題）

| 項目 | 規格 |
|---|---|
| 模型 | `log(1 + 評論數) = 歷史密度(300 m) × 業態大類 + 店齡（或缺失指標） + 是否連鎖 + 是否位於主街 + 捷運距離 + 價位 + 街區固定效果` |
| 標準誤 | 以街區為群集的穩健標準誤 |
| 樣本 | 分析單位 POI，排除業態「其他」 |
| 參照類別 | 熱食餐飲（目的型）（【待確認】） |
| 尺度 | 歷史密度標準化為 z 分數後進模型（【待確認】） |
| Holm 用的 p 值 | 所有「歷史密度 × 業態」交互項的聯合 Wald 檢定（群集穩健） |
| 證偽 | 交互項的信賴區間涵蓋 0 且窄。「窄」定義為：每個交互項的 95% 信賴區間都落在 ±0.10（log 單位，每 1 個標準差的歷史密度）之內（【待確認】門檻值） |
| 報告 | 各業態的歷史密度斜率與信賴區間（森林圖）；直接版與 PPI 修正版（業態與連鎖來自 LLM 時）。`ppi_py` 若不支援固定效果加群集標準誤，先以街區去平均處理固定效果，再用其 OLS 版本，並記錄在 deviations.md |
| 租金 | 無法直接觀測。街區固定效果與「是否位於主街」吸收街區層級的租金差異（提案書 5.2） |
| 敏感度 | 納入大橋頭重跑一次（時間允許） |

### H7　聚集在業種層級存在，個別決策卻是機會導向（探索）

| 項目 | 規格 |
|---|---|
| 變數 | 創立年份、創立當時附近的同業密度 |
| 方式 | 只做描述，不檢定、不宣稱證偽 |
| 執行條件 | LLM 抽到的創立年份太少時自動略過（【待確認】：建議門檻為至少 30 家有創立年份） |
