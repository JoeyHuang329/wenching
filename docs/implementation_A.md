## 3. 交接文件給隊友（C3 的任務）

**誰寫：** 黃旭寬。**什麼時候：** 11/11 晚上，結果凍結之後。**給誰：** 隊友 B 主筆，其他人協助。

這份文件要讓沒有寫程式的隊友，拿到之後就能開始做人文詮釋。建議用以下大綱：

1. **我做完了什麼：** 一段話說明資料、抽查結果、哪些假說成立或不成立（附圖）。
2. **你會拿到的檔案：** 每個 RQ3 案例一個資料夾，裡面有：
   - `summary.md`：店址、目標業態、統計層的前五名缺失特徵、三家最接近的成功對照（含 Google Maps 連結）
   - `evidence.md`：證據包，每項有編號、來源連結
   - `draft.md`：LLM 寫的說明草稿（11/13 才有）
3. **你要做的事：** 對每個案例回答四個問題：
   - 統計層列出的差異，在你讀過的訪談或歷史資料裡有沒有對應？
   - 有沒有「資料看不到、但訪談說了」的因素？是哪一位受訪者說的？
   - LLM 草稿有沒有說錯、說過頭（例如把關聯說成因果）？
   - 用三到五句話寫出你的詮釋，每一句標明依據（證據編號或訪談編號）。
4. **怎麼驗證你的詮釋（選做）：**
   - 找一位沒讀過該案例的隊友，只看證據包，判斷你的每一句話是否有依據。
   - 有受訪者回覆的案例，比較你的詮釋與他們的評分。
5. **注意事項：** 里長的不公開段落與政治評論不能用；不寫受訪者姓名，除非同意書已確認。
