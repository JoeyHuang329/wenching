# 抽查手冊

> 每人 30 筆，約 1.5–2.5 小時。**先打開 `docs/audit_form_example.xlsx` 看 10 筆填好的範例**，再開自己的表單。

## 你要填的檔案

`data/final/audit_form_編號_你的名字.xlsx`（Excel 版）。**不要填 CSV 版**，CSV 只是備份。

打開後有兩個工作表：
- **填寫**：一列一家店。只填**淡黃色**的欄位。
- **怎麼填**：規則的精簡版，填的時候可以切過去看。

## 為什麼要照這份手冊做

這 120 筆是整份研究唯一的「人工答案」，用來檢驗 LLM 標得準不準（Cohen's κ）。只要做到兩件事，結果就有效：

1. **用自己的判斷填，不看 LLM 的答案。** 表單上本來就沒有 LLM 的答案。
2. **填過的不改。** 改變想法就寫在備註欄。四個人都填完之前，不要互相討論答案。

## 每一列怎麼做

1. 讀**店名**、**Google 類別**、**店家文本**。文本就是 LLM 看到的內容；八成以上的店沒有網站，文本欄會寫「沒有文本」。
2. 需要的話點**開啟地圖**看照片或評論。
3. 用**下拉選單**填四欄：

| 欄 | 填什麼 | 選項 |
|---|---|---|
| ① 業態大類 | 這家店最主要在做什麼 | 熱食餐飲／咖啡茶飲甜點／傳統業種／選物與文創零售／文化空間／一般零售與品牌／其他／不明 |
| ② 是否文青 | 照下面的規則判斷，不要憑感覺 | 是／否／不明 |
| ③ 歷史敘事 | **文本裡**有沒有講到歷史 | 無／不明／建築／街區／家族，或組合，例如「建築;街區」 |
| ④ 判斷依據 | 你看了什麼 | `text`：只看表單；`text+maps`：有點開地圖 |

4. 有猶豫的地方就寫在**備註**，例如「店名像連鎖但不確定」。範例檔的備註示範了寫法。
5. 灰色的兩欄（第二輪）**現在先空著**。LLM 結果出來之後會另外發一份，讓大家判斷 LLM 的答案合不合理。

## ① 業態大類

- 選**最主要**的一個。賣咖啡也賣甜點的店選「咖啡茶飲甜點」。
- **傳統業種**：中藥行、蔘藥行、南北貨、乾貨、布行、茶行、老字號批發。
- **不是店家的**（寺廟、工會、公司辦公室、事務所、保險經紀）→「其他」，並在備註寫「非商業」。
- 完全看不出在做什麼 →「不明」。

## ② 是否文青

依序檢查，第一條符合的就是答案：

1. **連鎖**品牌（有「某某店」分店名的全國品牌）→ **否**
2. **獨立**的咖啡店，或可以坐下來喝茶的茶館 → **是**，不需要其他條件
3. 獨立書店、藝廊、展演空間、選物店、文創商品、手作工藝、設計工作室，**而且**看得到至少一項風格指標 → **是**
   - 風格指標：設計或美學主張、在地或歷史故事、手作或小量生產、閱讀或展覽活動
4. **甜點店**要有上面任一項風格指標才是**是**；雞蛋糕、路邊點心、傳統糕餅 → **否**
5. 手搖飲、中藥行、南北貨、布行、一般零售、餐廳 → **否**（就算正在轉型、包裝很好看也一樣）
6. 資料不足以判斷 → **不明**

## ③ 歷史敘事

**只看文本有沒有講，不是看這家店老不老。**

- **建築**：老屋、街屋、歷史建築、三進式
- **街區**：大稻埕或迪化街的歷史
- **家族**：傳承、第幾代、創立於某年
- 有好幾項就選組合（例如「建築;街區」）。
- 文本內容夠多（就算只是網站選單、購物車、公司登記資料）但沒講到歷史 → **無**
- 沒有文本，或文本只有一兩行 → **不明**

## 常見的坑

- **Google 類別常常是錯的。** 雞蛋糕攤被標成 cafe，珠寶店只有 point_of_interest。以店名和文本為準。
- **文本常常是網站選單或公司登記資料。** 那不是「沒有文本」，而是「有文本但沒講到歷史」，③ 填**無**。
- **店名有「老店」「百年」不算歷史敘事**，文本要真的講到才算。
- **不要因為認得這家店，就填資料裡沒有的資訊。** 如果點了地圖，④ 一定要填 `text+maps`。
- 看到個人姓名或電話，不要抄進備註，寫「含個資」就好。
- 有問題在群組問黃旭寬，但**不要互相討論答案**。

## 填完之後

存檔（保持 .xlsx 格式，**不要另存成 CSV**），放回 `data/final/`，檔名不要改，然後告訴黃旭寬。
