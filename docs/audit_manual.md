# 抽查手冊（草稿）

> 實作規劃 A 指派廖亭瑀、胡予馨於 11/9 上午撰寫定稿；這是 Claude 依提案書 8.4 節與實作規劃 B 第 3.3 節起草的版本，請直接修改。
> 抽查時段：**11/10 10:00–12:00**，四人各 30 筆，約一小時。

## 為什麼要照這份手冊做

這 120 筆是全研究唯一的「人工答案」。它決定 LLM 特徵能不能用（閘門一），也是修正 LLM 誤差的依據。只要做到下面兩件事，結果就有效：

1. **先填自己的判斷，再看 LLM 的答案。** 表單上一開始不會顯示 LLM 答案。
2. **填過的答案不改。** 討論時有不同意見，寫在備註欄，不要回頭改。

## 每一筆的步驟

1. 讀表單上的資料：店名、Google 類別、店家文本（沒有官網的只有店名與類別）。
2. 需要時可以打開 Google Maps 看店家頁面與照片。若有這樣做，`basis` 欄填 `text+maps`；只看文本填 `text`。
3. 填三個關鍵欄位（**先填，不看 LLM**）：

### h_category（業態大類）

熱食餐飲／咖啡茶飲甜點／傳統業種／選物與文創零售／文化空間／一般零售與品牌／其他／不明。定義與 `prompts/extraction_v1.md` 相同。

### h_is_wenqing（是否文青）：請照規則判斷，不要憑感覺

1. 連鎖品牌 → **否**。
2. 獨立的咖啡店、茶館（可以坐下來喝茶的空間）→ **是**（不需要其他條件）。
3. 獨立書店、藝廊、展演空間、選物店、文創商品、手作工藝、設計工作室，**而且**資料中看得到至少一項：設計或美學主張、在地或歷史故事、手作或小量生產、閱讀或展覽活動 → **是**。
4. 甜點店：要有上面任一項風格指標才算 **是**。
5. 手搖飲、中藥行、南北貨、一般零售、餐廳 → **否**（就算正在轉型、包裝很好看也一樣）。
6. 資料不足以判斷 → **不明**。

### h_history_narrative（歷史敘事）

可複選：建築（老屋、街屋、歷史建築）／街區（大稻埕的歷史）／家族（傳承、第幾代）。資料有足夠內容但沒提到歷史 → **無**；資料太少 → **不明**。

4. 填完三欄後，按「顯示 LLM 答案」，再填：
   - `llm_fields_reasonable`：其他欄位（連鎖、風格指標、客群、創立年份）是否合理？填「是」或「否」，「否」要寫哪一欄、為什麼。
   - `evidence_reasonable`：LLM 附的證據片段是否真的支持它的答案？

## 注意

- 不要因為「認得這家店」就填資料裡沒有的資訊。判斷依據要和 LLM 看到的一樣，否則比較不公平。若用了 Google Maps，就在 `basis` 標記。
- 遇到疑似個人姓名、電話等個資，**不要抄進表單**，在備註寫「含個資」即可。
- 有問題在群組問黃旭寬，但**不要互相討論答案**，直到全部填完。
